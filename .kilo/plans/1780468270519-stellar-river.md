# Plan: Refactor NoteDisplayClient Header to Single-Line Inline Layout

## Objective
Optimize vertical space in `StickyNoteHeader` by merging the separate metadata row into the main header flex row.

## Target File
- `app/dashboard/notes/[id]/NoteDisplayClient.tsx`

## Changes

### In `StickyNoteHeader` component (lines ~863–987)

1. **Remove the standalone `metadata` constant** (currently lines 890–901)
2. **Remove the conditional metadata block** below the main flex row (currently lines 977–983)
3. **Restructure the main header flex row** to integrate metadata inline:

```tsx
<div className="flex items-center gap-2 sm:gap-3">
  {/* Back button — unchanged */}
  <button ...>...</button>

  {/* Title + metadata group */}
  <div className="flex min-w-0 flex-1 items-center gap-2 sm:gap-3">
    <h1 className={cn(
      "min-w-0 flex-1 truncate font-bold tracking-tight text-primary will-change-transform",
      isCompact ? "text-base sm:text-lg" : "text-xl leading-tight sm:text-2xl"
    )} title={note.title}>
      {note.title}
    </h1>

    {/* Metadata items — hidden when compact */}
    {!isCompact && (
      <div className="flex shrink-0 items-center gap-1.5 sm:gap-2 overflow-hidden">
        <TypeBadge type={note.type} />
        <UpdatedAt updatedAt={note.updatedAt} />
        <TopicChip topicId={topicId} topicTitle={topicTitle} fallback={qaTopic} />
        {/* Prevent tag list from wrapping into multiple lines */}
        <div className="flex !flex-nowrap items-center overflow-hidden">
          <TagList tags={note.tags} compact />
        </div>
      </div>
    )}
  </div>

  {/* Action buttons — unchanged */}
  <div className="flex shrink-0 items-center gap-1.5 sm:gap-2">
    <button ...>Favorite</button>
    <button ...>Edit</button>
    <button ...>Delete</button>
  </div>
</div>
```

## UI/UX Improvements

### Reduced sizes
- Inline metadata badges and chips: use `text-[9px]`, `h-6 py-0.5 px-1.5`, icons `h-3 w-3`
- Action buttons in `StickyNoteHeader`: `h-7 w-7` for icon-only buttons, `text-[11px]`, `gap-1` spacing
- Titles and labels scaled down by one size step to fit the single-line constraint

### Tooltips (reuse existing `Tooltip` from `TopicDetailClient`)
- Extract `Tooltip` from `app/dashboard/topics/[id]/TopicDetailClient.tsx` into a shared component (e.g. `@/components/ui/Tooltip`)
- Update `TopicDetailClient` to import from the shared file
- Import and wrap action buttons with `<Tooltip text="...">`:
  - Back: "Go back"
  - Favorite: {isFavorite ? "Remove from favorites" : "Add to favorites"}
  - Edit: "Edit note"
  - Delete: "Delete note"

## Result
- Non-compact state: single horizontal row containing back, title, metadata, and actions
- Compact state: single horizontal row containing back, title, and actions (metadata hidden as before)
- Eliminates the second metadata row and reduces vertical footprint
- Title remains prominent and truncates gracefully when space is limited
- Reduced icon/text sizes improve density without sacrificing readability
- Tooltips preserve affordance for smaller controls
